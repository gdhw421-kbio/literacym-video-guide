# LiteracyM 화상진료 참여 안내 (몽골어)

정적 웹페이지. 빌드 과정 없음.

## 구성
- index.html — 안내 페이지
- images/ — 앱 화면 스크린샷 (600px JPG)
- netlify.toml — Netlify 설정 (루트 폴더 그대로 게시)

## 배포
1. 이 폴더 내용을 GitHub 저장소 루트에 올린다.
2. Netlify → Add new site → Import from Git → 저장소 선택.
3. Build command: 비움 / Publish directory: `.` → Deploy.
